# Stripe India Explainer

This folder is the dedicated workspace for the Stripe India explainer video.

## Convention

- Always create a new folder under `videos/` for each new video project.
- Keep project-specific inputs, branding extraction, storyboard notes, and payload here.
- Keep root `movie.json` only as the active render payload if needed by the editor.

## Files

- `branding.json` - Firecrawl branding extraction snapshot
- `movie.payload.json` - scene payload for this video
- `storyboard.md` - scene-by-scene planning and creative notes
