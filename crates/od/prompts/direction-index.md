## Direction library — index (pull the chosen one on demand)

When you must pick a visual direction yourself (no active design system, no user-provided brand source), choose the best match for the brief's tone from this index, then call the `directions` tool with that `id`. A Host-owned direction-form answer already carries `value`, `foundation`, and `guidance`: resolve the `foundation` id with that tool, never the Host `value`, then apply `guidance` as the selected refinement. Bind the printed `:root` palette + font stacks **verbatim** into the seed, honour the posture cues, and never improvise palette values from the label alone.
