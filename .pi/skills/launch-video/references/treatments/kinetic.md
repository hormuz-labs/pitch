# Kinetic typography

Language is the visual material. Write a concise sequence before animating it.
Use changes in scale, position, masks and rhythm to express meaning; a repeated
word-by-word entrance is not a concept. Keep each readable state short and stable
enough to register, clearing it as the next idea takes focus.

Product imagery or an icon can provide proof between phrases. Do not add a
second layer of subtitles, captions or feature cards beneath the primary type.
Narration is optional; if present, align the type with the spoken idea.
